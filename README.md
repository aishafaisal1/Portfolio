# Ayesha Faisal — GitHub Pages portfolio

This folder is a static website. It uses HTML, CSS, vanilla JavaScript, image assets and MP4 video files.

Two pages: `index.html` (the front page — hero, selected work, project notes, motion, about, contact) and `archive.html` (the archive — every piece filed into filterable folders, with a click-to-enlarge viewer).

## Publish with GitHub Pages (no build step)

1. Create a **public** GitHub repository, for example `ayesha-faisal-portfolio`.
2. Extract this ZIP on your computer. The extracted folder should contain `index.html`, `archive.html`, `styles.css`, `archive.css`, `script.js`, `archive.js`, `README.md`, and the `assets/` folder directly.
3. In your GitHub repository, choose **Add file → Upload files**. Upload the contents of the extracted folder (not an extra enclosing folder).
4. Commit the upload to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
6. Set the branch to **main** and the folder to **/(root)**, then click **Save**.
7. Wait for the Pages deployment to finish. Open the URL shown in **Settings → Pages**. It will usually look like `https://YOUR-USERNAME.github.io/ayesha-faisal-portfolio/`.

## Important

- Keep `index.html`, `archive.html`, the CSS/JS files, and `assets/` together at the repository root.
- Do not upload only `index.html`; the assets folder and both MP4 files are required.
- The repository must be public to use GitHub Pages on GitHub Free.
- GitHub Pages publishes public websites. Check all contact details and obtain permission to show client work before publishing.
- This is a static site. It does not provide server-side code, a database, or a contact-form backend. The email link opens the visitor's email app.
- After future edits, upload/commit the changed files; GitHub Pages will publish the new version.
